# A사 Zero Trust 적용 방안
## 5대 원칙 적용 방안
- ID:계정이 회사에 등록되어 있는지 없는지 확인한다
- Device: 장치가 최신상태인지 그리고 백신같은 보안 설정이 되어있는지 확인한다
- Network: 서버 구역과 직원 PC 구역을 나누고, 필요한 포트만 연다
- Application:직원들마다 허용 가능한 프로그램을 설정하고 허용이 되어있는 프로그램에게만 접근 가능하게 한다 
- Policy:상황 따른 정책을 수립한다(새벽에 접속시 리스크 스코어링 해외 ip일경우 리스크 스코어링)
## 판단과 집행
- PDP(결정):id 계정이 회사 계정에 있는지 확인(필수 조건)
장치가 등록되어있는지 확인(필수조건)
장치의 안정성 및 업데이트를 확인한다(필수조건)
정해져 있는 포트번호와 구역을 무시할경우 차단한다(디폴트 디나이)
허용되지 않은 프로그램에 접근할경우 리스크스코어링을 한다 
회사에 맞는 정책을 수립한다
- PEP(집행):필수조건에 맞지 않는경우 차단
디폴트 디나이 설정
스코어링과 그에 따른 위험등급에 따라 분기로 처리
허용 되지 않은 프로그램 정책위반 리스크 스코어링 추가
## 흐름도
```
사용자 --요청--> PEP --문의--> PDP
```
## 최소권한 기준 (목록에 없으면 거부)
- 재무팀:정산 내역
- 영업팀:영업 실적
- 서비스 계정 batch-night:정산 내역
