### 문제 6-1 · 지터 함수 직접 만들기

- (가) 직접 만든 `jitter` 함수를 독스트링과 함께 아래 코드 블록에 붙여 넣어 주세요.
  - 쓸 내용: 독스트링을 쓴 함수를 복사해 아래 코드 블록에 붙여 넣기
  - 답:

```
def jitter(got):                          # 받은 값 리스트 got 으로 지터를 구해 리턴하는 함수이다. 이 함수를 직접 만든다
    """
    
    지연시간을 받아서 지터를 계산한다
    입력: 회선들의 지연시간리스트
    리턴: 지터값을 리턴합니다
    """
    # 1. total 을 0 으로 시작한다
    total = 0
    # 2. for 와 range(1, len(got)) 로 위치 i 를 꺼내, i 번째 값과 바로 앞 값의 차이의 절댓값을 total 에 더한다
    for i in range(1, len(got)):
        total = abs(got[i-1] - got[i]) + total
    # 3. total 을 (got 의 개수 - 1) 로 나눈 값을 리턴한다
    return total/(len(got)-1)
                               # ← 계산을 만들기 전에 넣어 둔 임시 값이다. 이 줄을 지우고 위 1 ~ 3 을 코드로 쓴다 (4줄 이하)
```

  - 쓸 내용: 터미널 출력 세 줄을 복사해 붙여 넣기
  - 답:회선 A | 지연 21.9 ms | 지터 1.1 ms | 손실 0 %

- SaaS 접속이 느린 원인 구간과 그 근거를 적어 주세요.
  - 쓸 내용: ① 원인 구간 ② 근거(tracert 에서 뛴 값) ③ 사내 구간이 정상이라는 근거
  - 답:4번과 5번 홉 사이에서 6ms에서 48ms로 증가했고 이후에도 49~50ms를 유지했다. 사내 공유기와 방화벽은 1~2ms로 정상이라 통신사 해외 연결 구간에서 지연이 발생한 것으로 보인다.

### 4. 한계와 다음 확인

- 이 진단으로 알 수 없는 것 하나와, 다음에 확인할 것 하나를 적어 주세요.
  - 쓸 내용: ① 알 수 없는 것(예: 한 시각의 값이라는 점) ② 다음 확인(시간대를 바꿔 다시 재기 · 구간 운영자에게 확인 요청)
  - 답:한 번 측정한 결과라 일시적인 지연인지 확정할 수 없다. 다른 시간대에도 반복 측정하고 결과를 첨부해 통신사에 확인을 요청해야 한다.
