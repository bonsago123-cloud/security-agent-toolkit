# 1과목 회고 (이름)

## 내가 만든 것
- 서버로 이상하거나 수상한 침입을 감지하고 기록하고 보고하는 코드

## 가장 어려웠던 것
- 후반부에 함수가 많아지면서 함수의 내부와 이 함수가 정확히 뭘하는지 기억해내기 어려웠고
각 모듈에 대해 깊이 알지 못해 마음이 불편한게 가장 어려웠다

## 리뷰에서 찾은 것과 고친 것
- 내가 짠 코드에선 어렵게 보이는 코드를 보기 쉽게 보이도록 고쳤고
이미 짜여진 코드는 현재 기준으로는 지식의 문제로 인해 나의 기준으로 고칠게 안보인다

## 캡스톤에서 더 해 보고 싶은 것
- 현재 만들어진 이 탐지기의 취약점을 여러점을 찾아내 그걸로 뚫어보고 그리고 그 취약점을 보안한 코드를 짜는걸
두번 이상 수행해보고 싶다
